CORREÇÃO DAS OFERTAS

O carrossel só consegue identificar os produtos se o Apps Script enviar a coluna G no HTML.

1. Abra o Apps Script ligado à planilha.
2. Substitua o conteúdo do arquivo Code.gs pelo Code.gs deste pacote.
3. Troque o número 5511999999999 pelo WhatsApp da DG Eletros.
4. Clique em Implantar > Gerenciar implantações > Editar.
5. Selecione Nova versão e clique em Implantar.
6. Mantenha o mesmo link /exec no index.html.
7. Na coluna G, use SIM para os produtos em oferta.

O index.html também foi corrigido para evitar cache e reconhecer SIM, true, 1 ou classes de oferta.
